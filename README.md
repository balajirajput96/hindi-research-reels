# 3000 Hindi Research Reels

This repository contains the **non-secret, reproducible production specifications** for a 3,000-reel Hindi educational series on psychology, neuroscience, philosophy, spirituality, cognition, and behavior. Rendered media is deliberately excluded from Git because it is large; QC-passed deliverables and their source metadata are retained in the connected Google Drive production root. The canonical production state is `catalog/canonical_production_state.json`; the older `catalog/production_state.json` is preserved as historical source data.

Every reel follows the same completion contract: a verified evidence record, an evidence-classified Hindi script, visual and narration plan, rendered 9:16 video, technical and editorial QC, Drive upload verification, and a persistent checkpoint update. Scientific evidence, expert interpretation, philosophical concepts, and spiritual or traditional beliefs must remain explicitly separated.
